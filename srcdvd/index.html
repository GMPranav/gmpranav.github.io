SRCDVD

speedrun.com Deleted Video Detector

An automated auditing utility that detects runs with unviewable (deleted, private, or expired) YouTube and Twitch video links for any given game on speedrun.com. By correlating the speedrun.com REST API with Google YouTube API v3 and Twitch API, it isolates dead links and exports actionable audit logs for community moderators.

The Problem

Why Video Auditing Matters

Link Rot on Leaderboards

Over months and years, runners delete YouTube channels, make videos private, or submit Twitch stream links that automatically expire after 14 to 60 days. This leaves historic verified runs on leaderboards without video proof.

Painful Manual Verification

Large leaderboards contain hundreds or thousands of submitted runs. Manually opening every run URL to test whether the video still plays takes dozens of hours and is almost impossible for volunteers to maintain.

Automated Batch Resolution

SRCDVD scans hundreds of runs concurrently using official batch endpoints (querying up to 50 YouTube IDs in a single HTTP request), outputting a clean report of missing VODs in seconds.

Pipeline Architecture

4-Stage Detection Pipeline

1

Fetch Verified Runs

Queries the speedrun.com REST API for all verified runs of the target game. Outputs full metadata to data.txt.

2

Extract & Isolate Video Links

Parses video URLs from the dataset, filters for YouTube and Twitch domains, and saves normalized video URLs to links.txt.

3

Batch API Availability Query

Extracts video IDs and executes batch lookups against Google YouTube API v3 and Twitch API. Videos that fail to return are marked missing.

4

Cross-Reference & Report

Cross-references missing video IDs against data.txt to retrieve the exact speedrun.com submission links, saved to missinglinks.txt.

Configuration

API Authentication Setup Guide

YouTube Data API v3

Google Cloud Console Setup

  1. Create a new project in the Google Cloud Console.
  2. In the sidebar, navigate to APIs & Services → Library.
  3. Search for YouTube Data API v3 and click Enable.
  4. Go to Credentials → click Create Credentials → select API key.
  5. Copy your generated API key and supply it when prompted by SRCDVD (or type skip to bypass YouTube verification).
Twitch Helix API

Twitch Developer Setup

  1. Log into the Twitch Developer Console.
  2. Click Register Your Application, give it a name (e.g. SRCDVD Audit), set OAuth Redirect to http://localhost, and category to Analytics Tool.
  3. Copy the Client ID and generate a new Client Secret.
  4. Supply both values when prompted by SRCDVD (or type skip to bypass Twitch verification).
File Artifacts

Generated Output Files

data.txt

Raw Run Records

Full JSON dump of verified run objects from speedrun.com's REST API containing player names, dates, times, and submission links.

links.txt

Isolated Video URLs

Filtered list of YouTube and Twitch URLs extracted from run submissions for batch processing.

missinglinks.txt

Actionable Audit List

Final list of speedrun.com run URLs whose VODs returned deleted, 404, or private status errors during the API batch scan.
