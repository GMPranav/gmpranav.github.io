AppleWin Emulator · Exact 12 FPS Frame-Clock IGT

Prince of Persia (Apple II)

File: PrinceOfPersiaApple][.asl

Download .asl
Platform: AppleWin 1.30.3.0 Timing: Frame-accurate IGT (Ticks / 12.0) End Trigger: Princess Room (0xFF)

Features & Implementation Details

  • Automated Start: Automatically starts the timer the exact tick Level 1 begins (current.Level == 1 && current.Ticks == 0).
  • True 12 Hz Apple II Clock: Reads emulator frame ticks directly from memory and converts to accurate Game Time: current.Ticks / 12.0.
  • Precise Splits: Fires split triggers immediately when Prince exits level doors (levels 1 through 13) and when Level 14 EndGame byte turns to 0xFF.
  • Auto-Reset: Detects menu resets via memory flags Reset1, Reset2, and Reset3.
AppleWin Memory State Block ASL 
state("AppleWin")
{
    byte Level   : "AppleWin.exe", 0x1F5498, 0x031C; // Level 1-14 changes
    ushort Ticks : "AppleWin.exe", 0x1F5498, 0x0306; // Ticks one per frame
    byte EndGame : "AppleWin.exe", 0x1F5498, 0xE14A; // 255 at Princess room
}

DOSBox-X 0.83.8 · Savestate Practice & Strat Timing

DOSBox-X 0.83.8 IGT

File: DOSBox_0.83.8_IGT.asl

Download .asl
Platform: DOSBox-X 0.83.8 Target: Classic DOS In-Game Timer Use Case: Savestate Practice & Route Optimization

Features & Implementation Details

  • Practice in True IGT: Because standard DOSBox does not support savestates, DOSBox-X is preferred for practice. This script reads the game's remaining minutes and frame seconds directly from DOSBox-X memory.
  • Frame-Accurate Conversion: Accurately calculates elapsed game frames ((60 * 720) - adjustedFramesLeft) / 12.0 into seconds.
  • Strat Comparisons: Compare room strats and tricks in exact game time down to the tick!
DOS Timer Math ASL 
gameTime
{
    int minutesLeft = current.MinutesLeft - 1;
    int totalFramesLeft = (minutesLeft * 720) + current.FrameSeconds;
    int elapsedFrames = 60 * 720 - totalFramesLeft;
    return TimeSpan.FromSeconds(elapsedFrames / 12.0);
}
Installation

How to Install in LiveSplit

Step 1

Download the Script

Download the desired .asl file from above or copy the raw URL from the repository.

Step 2

Open Layout Editor

In LiveSplit, right-click anywhere → click Edit Layout... → click the + button → Control → Scriptable Auto Splitter.

Step 3

Point to Script

Double-click Scriptable Auto Splitter in your layout list, click Browse... and select your downloaded .asl file.

Step 4

Compare Against Game Time

Right-click LiveSplit → Compare Against → choose Game Time if the script provides IGT (e.g. PoP Apple II or DOSBox-X).
