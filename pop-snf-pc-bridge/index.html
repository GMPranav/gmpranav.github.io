Native Windows PC Port · ShiVa3D Engine · Dynarmic JIT Runtime

An authentic, native Windows x64 PC port of the classic 2013 remake of Prince of Persia: The Shadow and the Flame. Rather than relying on heavy Android emulators that virtualize an entire operating system and kernel, this project runs the original ARMv7 client library (libS3DClient.so) natively as a standalone 64-bit Windows executable through Dynarmic dynamic retranslation, Desktop OpenGL, OpenAL Soft, and a dedicated 2000s-style configurator.

Engine Capabilities

Core Engineering Highlights

Zero OS Emulation Overhead

No BlueStacks, Nox, or Android VM hypervisors. The game's ARMv7 ELF binary runs directly inside Windows user space with near-zero latency, negligible CPU footprint, and instant startup times.

Dynarmic Dynamic Retranslation

Employs a custom precompiled Dynarmic JIT fat library to retranslate 32-bit ARM machine code directly into host x86-64 machine instructions on the fly with optimized register mapping.

4K UHD & Desktop OpenGL

Bridges mobile OpenGL ES 2.0 to Desktop OpenGL compatibility profile. Features real-time software ETC1 texture decompression, true 16:9 widescreen resolutions up to 3840x2160, MSAA 8x, and 16x Anisotropic Filtering.

OpenAL Soft 3D Spatial Audio

Intercepts Android OpenSL ES and OpenAL calls and bridges them directly to modern 64-bit OpenAL Soft, preserving authentic surround sound, environmental reverb, and crystal-clear music.

Full Controls & Gamepad Support

Powered by SDL2 with support for XInput/DirectInput controllers, mouse buttons (Left, Right, Middle, Extra buttons, Scroll wheel), and customizable keyboard layouts with conflict resolution.

Nostalgic Config Launcher

Includes PoPSnF_Launcher.exe, a retro 2000s Prince of Persia style launcher with 1-click APK asset extraction, Dolphin-style key binding, and full undo/redo configuration history.

Getting Started

Setup & Installation Guide

01

Requirements

- 64-bit Windows 10 or 11
- OpenGL 3.3 compatible graphics card
- Microsoft Visual C++ 2015-2022 Redistributable (x64)
- A legitimate Android .apk of Prince of Persia: The Shadow and the Flame (v1.0.0 or later)

02

Extract Game Files

Download the latest release from GitHub. Launch PoPSnF_Launcher.exe and drag-and-drop your game .apk into the extraction prompt. The launcher will automatically unpack and verify the required assets in seconds.

03

Configure & Play

Choose your preferred resolution (e.g. 1080p, 1440p, or 4K UHD), toggle VSync or MSAA, adjust your keybindings or controller layout, and click Launch Game!
